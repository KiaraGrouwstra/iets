iets is a re-implementation of the Nix client in Rust. It is mostly, but not
fully, compatible with Nix. This is the first release.

## Download

One static musl binary per platform. It needs no `/nix/store`, no
nix-daemon and no shared libraries.

```sh
curl -Lo iets https://github.com/numtide/iets/releases/download/v0.1.0/iets-0.1.0-x86_64-linux
chmod +x iets
./iets version
```

`SHA256SUMS` lists the checksums. For aarch64-linux, use
`iets-0.1.0-aarch64-linux`. With Nix, `nix run github:numtide/iets/v0.1.0`
also works.

## What works

- Evaluation: 1.7–1.9x faster than Nix 2.34.8 on NixOS configs on one core,
  3.1–3.5x on four.
- `iets build`, `eval-jobs`, `search`, `diff`, `prefetch` and
  `print-dev-env`, in place of nix-build, nix-fast-build, nix-eval-jobs,
  nix search, nix-diff, nurl and nix-direnv.
- Locked local flakes, with `github:`, `gitlab:`, `sourcehut:` and `tarball`
  inputs.
- Builds on a nix-daemon or on a `grpc://` builder.
- Under the classic names (`nix-build`, `nix`), what iets does not do falls
  back to the real `nix`.

## What does not work yet

- No nix-daemon and no store of its own.
- No registry refs (`nixpkgs#hello`), no remote flake roots, no
  `nix flake lock`.
- No import-from-derivation.
- `fetchurl` and `fetchTarball` need a `sha256`. No `fetchClosure`.
- Linux only for the static binary. macOS builds from the flake.

The full list is in
[docs/reference/divergences.md](https://github.com/numtide/iets/blob/v0.1.0/docs/reference/divergences.md).
iets is LLM-ware; see the README for what that means.
